# NexRoute Pro (Prototype)

Arabic-first SaaS prototype for shipping aggregation in MENA.

## Pages
- `index.html`: Marketing landing page with RTL layout, animations, pricing, FAQ and CTA.
- `dashboard.html`: Merchant dashboard prototype (overview, orders, shipments, comparison, COD, settings).

## Run locally
```bash
python3 -m http.server 4173
```
Then open `http://localhost:4173`.

## Scope implemented
- Landing sections required in prompt (Hero, Features, How it works, Carriers, Pricing, Testimonials, FAQ, CTA, Footer).
- Dashboard UI inspired by provided screenshots with maroon palette and quick stats sidebar.
- Mock comparison engine and mock order/shipment/COD data.
